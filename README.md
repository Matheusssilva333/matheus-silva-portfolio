# Matheus Silva — Portfólio profissional

Portfólio profissional restaurado do histórico do repositório `Jarvis` e reorganizado em React + TypeScript + Vite.

## Conteúdo

- Perfil profissional, experiência, projetos e stack técnica;
- currículo para download e contato direto por WhatsApp/e-mail;
- depoimentos com visualização ampliada;
- assistente local de perguntas frequentes, sem chave de API exposta no navegador;
- layout responsivo, acessível e com suporte a `prefers-reduced-motion`.

## Executar

```bash
npm install
npm run dev
```

Para validar a produção: `npm run build`.
